# 提案プロジェクト名：エージェントベースモデルと量子アニーリングの統合による社会システム最適化

**提案者名：影山稜真**

---

## １．プロジェクトの背景、目的、目標

### 1.1. 背景

高校時代にPythonで経済政策のシミュレーションプログラムを自作していました。消費税率や法人税率などのパラメータを変えながらGDPや失業率への影響を調べるものでしたが、パラメータが増えると「組み合わせ爆発」という壁にぶつかりました。10種類のパラメータを5段階で試すと約1000万通りの組み合わせになり、遺伝的アルゴリズムを試しても局所解に嵌まりやすく、真の最適解には届きませんでした。

D-Wave社の量子アニーラはクラウド経由で使えるようになっており、金融・物流での実用例も増えています。ただ、経済政策や社会システムのような複雑な領域への応用はほとんど手がついていません。本プロジェクトでは、その高校時代の問題を出発点として、**エージェントベースモデル（ABM）と量子アニーリングを代理モデルで繋ぐ**ことで、この領域での有効性を検証します。

### 1.2. 目的・技術的アプローチ

本プロジェクトでは、**ABM × 代理モデル × 量子アニーリングの3層統合フレームワーク**を開発します。

これまでの量子アニーリング応用は、数式で明確に書ける目的関数を扱うものが中心でした。社会システムはそうではなく、多数のエージェントの相互作用から予測しにくい挙動が生まれます。単純な数式に落とし込むこと自体が難しいのです。本プロジェクトは、ABM・代理モデル・量子アニーリングの3つを繋ぐことでこの壁を越えようとしています。

**ABMを選んだ理由——経済モデルの妥当性問題からの解放**

IS-LMやDSGEのようなマクロ経済モデルを使う場合、「そのモデルが経済現実を本当に表しているか」という問題が常についてまわります。工学系の自分がその議論に踏み込むのは限界があると感じていました。ABMなら、「税率が上がれば消費を減らす」「需要が落ちれば雇用を削る」といった、専門知識がなくても自明に受け入れられる行動ルールだけで組み立てられます。「モデルは経済学的に正しいか」ではなく「この行動は人間として自然か」という問いに変わるので、設計・検証のハードルが格段に下がります。

**3層パイプラインの概要**

```
ABM シミュレーション
  → ラテン超方格法でサンプリング（1000〜10000点）
    → 代理モデル（二次多項式 / ガウス過程回帰）で目的関数を近似
      → QUBO 変換（PyQUBO で自動生成）
        → 量子アニーリング（D-Wave） で最適解探索
          → 古典手法（遺伝的アルゴリズム等）と性能比較
```

### 1.3. 目標

**開発目標**

1. ABMシミュレータ（最終目標：1000エージェント、15パラメータ）
   - 個人・企業エージェントの相互作用、GDP・税収・ジニ係数等の創発
   - 実行時間：100エージェント × 100ステップ < 1ミリ秒

2. 代理モデル構築モジュール
   - サンプリング手法（ラテン超方格法）、多項式回帰・ガウス過程回帰・LASSO
   - 精度評価：交差検証によるR²スコア（目標 R² > 0.8）

3. 量子アニーリング最適化モジュール（3タイプ、詳細はセクション4）
   - Type 1（~150変数）：D-Wave 量子アニーラで直接実行
   - Type 2（~2000変数）：D-Wave 量子アニーラで直接実行
   - Type 3（多期間、大規模）：**D-Wave Leap ハイブリッドソルバー（LeapHybridSampler）を利用**

4. 比較検証モジュール：遺伝的アルゴリズム、シミュレーテッドアニーリング、ベイズ最適化、ランダムサーチ

**検証目標**

5. 代理モデル精度評価（R² > 0.8）
6. パラメータ数を変えた性能評価（5・10・15個）
7. 量子アニーリングと古典手法の性能比較
8. **ABMの複雑さと代理モデル精度の系統的調査**（L1〜L4の4段階で複雑さを変化させ、二次近似が成り立つ上限を探る）

**成果物**

- ABM + 代理モデル + 量子最適化の統合シミュレータ（主にCLI、補助的なWebビューアを添付）
- ソースコード（GitHub公開）、検証結果レポート、技術ドキュメント

### 1.4. 競合との差別化

既存の量子アニーリング応用は、数式で書ける目的関数を持つ問題（金融・物流）に集中しています。そこにABMのような複雑なシミュレーションを繋ぐ試みはほとんど見当たりません。「ABM出力を二次QUBO化する方法論」と「時間ステップをまたぐ多期間ミクロ離散政策の量子最適化」の2点が、本プロジェクトの軸となる新規性です。

## ２．斬新さの主張、期待される効果など

### 【技術シーズの優位性】

量子アニーリングは量子トンネル効果によって局所最適解を抜け出し、広い解空間を探索できます。PyQUBOやD-Wave Leapといった実用的なライブラリとクラウド環境がすでに整っており、開発期間内に動くシステムを作れる見通しが立っています。

### 【ABMを採用することの優位性：経済モデルの妥当性問題からの解放】

IS-LMやDSGEのようなマクロ経済モデルには「そのモデル自体が現実を正しく表しているか」という問題がつきまといます。工学系の立場でその議論に踏み込むのは難しい。ABMは「税率が上がれば消費を減らす」「需要が落ちれば雇用を削る」という、誰でも納得できる行動ルールだけで動きます。「モデルは妥当か」という問いが「この行動は自明か」という問いに変わり、経済学の専門知識なしに設計・検証できます。

**本プロジェクト独自の接続点：**

ABM → 代理モデル（二次多項式）→ QUBO変換 → 量子アニーリングというパイプラインは、上記のどの先行研究も実現していません。この統合における新規性は3点あります。

1. **ABM出力を二次QUBO形式で近似する方法論**  
   代理モデルを「量子アニーラに入力できる形式」に制約して作るのは、従来のSAOやBOとは根本的に異なる設計の要請です。近似精度と量子実行可能性のトレードオフという、これまで誰も正面から扱っていない問題を研究課題として設定します。

2. **エージェント個別のミクロ離散政策を量子で最適化**  
   先行研究はマクロな連続パラメータの調整に留まっています。本プロジェクトは「誰に補助金を配るか」というエージェント単位の離散的な割り当てを直接最適化します。この問題構造は量子アニーリングの離散最適化が得意とする領域に合致しています。

3. **時間ステップをまたぐ多期間動的最適化のQUBO定式化**  
   先行研究はすべて単一時点の静的な最適化です。本プロジェクトのType 3では「毎月誰に給付金を配るか」をT期間まとめて最適化するため、時刻 t の変数 `x_{i,t}` と時刻 t+1 の変数 `x_{i,t+1}` の依存関係をQUBO行列に埋め込みます。この時間方向の結合が行列を密にし、古典ソルバーが苦手とする構造を作り出します。時間ステップ間の動的依存関係を持つABMを量子アニーリングで最適化するという定式化は、先行研究には見当たりません。

### 【他分野への展開可能性】

本プロジェクトで作る「複雑シミュレーション + 代理モデル + 量子最適化」のパイプラインは、都市交通の信号制御、感染症の介入策設計、電力の供給計画など、社会システムを扱う他の分野にもそのまま転用できます。

## ３．どのような社会的課題を解決したいか

### 【本プロジェクトの位置づけ】

消費税の逆進性や格差拡大は現実に存在する問題です。このプロジェクトはそこを出発点としつつ、まずは「複雑なシミュレーション + 代理モデル + 量子最適化という統合が技術的に成立するか」を明らかにすることを第一の目的とします。実用化はその先の話で、技術的基盤の確立を優先します。

### 【解決すべき社会的・技術的課題】

複雑な社会システムの政策最適化では、「限られた予算でどの政策が一番効くか」を探すこと自体が計算量的に困難です。たとえば1000世帯への給付金を4段階で設定する場合、全探索は4^1000通りで現実的ではなく、今は専門家の経験則や粗い探索に頼っています。この問題にABM × 代理モデル × 量子アニーリングの組み合わせで挑みます。

### 【ケーススタディ：2014年消費税増税を前提とした給付金最適化】

技術検証の具体的な対象として、2014年の消費税増税（5%→8%）に対する低所得世帯への給付金配分最適化を使います。歴史的に結果が分かっている事例なので、「ABMが実際の消費減少のトレンドを捉えられているか」を総務省の家計調査データと照らして確認できます。

- **ABM**：所得層別の消費行動の変化と企業の雇用調整をエージェントの行動ルールで再現
- **代理モデル**：配分パターンと消費総額・ジニ係数の関係を二次多項式で近似
- **量子最適化（Type 2）**：1000世帯への給付金レベル（2ビット：なし/小/中/大）を~2000変数のQUBOとして最適化。D-Wave量子アニーラで直接実行
- **目的関数**：消費総額の落込みを最小化しつつジニ係数の悪化も抑える多目的最適化。制約は総給付額 ≤ 予算上限

### 【社会への貢献経路】

実装とドキュメントをすべてOSSで公開します。社会シミュレーション系の研究者が自分のABMをこのパイプラインに載せて量子最適化を試せるようになることが、短期的な社会的価値です。量子デバイスの性能が上がっていけば、政策立案の実際の場面でも使えるツールに育てられると考えています。

## ４．具体的な進め方

### 【開発する主要コンポーネント】

**1. ABMシミュレータ**

1000人規模のエージェント（個人・企業）が相互作用する経済シミュレーションです。「税率が上がれば消費を減らす」「需要が増えれば雇用を増やす」といった、経済学の高度な理論に頼らない行動ルールだけで動かします。GDP・税収・失業率・ジニ係数はエージェントの行動の積み重ねから自然に生まれます。実行時間は100エージェント × 100ステップで1ミリ秒未満です。

**2. 代理モデル構築モジュール**

1. ラテン超方格法で1000〜10000点をサンプリング（全実行時間：1〜10秒）
2. 各サンプルでABMを走らせてマクロ指標を記録
3. 多項式回帰（二次）・ガウス過程回帰・LASSOを比較（目標 R² > 0.8）
4. 回帰係数からQUBO行列を自動構築：f(x) ≈ Σ aᵢxᵢ + Σ bᵢⱼxᵢxⱼ

**3. 量子アニーリング最適化モジュール**

| Type       | 問題設定                                                     | 変数規模                                  | 実行方法                                                  |
| ---------- | ------------------------------------------------------------ | ----------------------------------------- | --------------------------------------------------------- |
| **Type 1** | 政策パラメータの多ビット二値化（例：消費税率を2ビット4段階） | 50パラメータ × 3ビット ≈ **150変数**      | D-Wave 量子アニーラ（直接実行）                           |
| **Type 2** | エージェント個別の給付金割り当て（2ビット、予算制約付き）    | 1000エージェント × 2ビット ≈ **2000変数** | D-Wave 量子アニーラ（直接実行）                           |
| **Type 3** | Type 2 の多期間拡張：毎月の給付配分を一括最適化              | 1000 × 2ビット × 12ヶ月 ≈ **24,000変数**  | **D-Wave Leap ハイブリッドソルバー（LeapHybridSampler）** |

Type 1・2は2000変数以下なので、D-Wave Pegasusグラフへのminor embeddingを経て量子アニーラで直接実行できます。Type 3の24,000変数は現行の量子アニーラ（5000+物理量子ビット）には大きすぎるため、D-Wave Leapのハイブリッドソルバー（LeapHybridSampler）を使います。このソルバーは量子と古典を自動的に組み合わせて最大100万変数のQUBOを処理でき、多期間最適化はここに自然に収まります。

Type 3の面白さは、1年間（12ヶ月）の給付金配分を一括で最適化する点にあります。「今月の消費が来月の所得に影響する」という時間方向の依存関係がQUBO行列を密にし、静的な割り当て問題より古典ソルバーが苦手とする構造になります。

**4. 古典最適化モジュール（比較用）**

遺伝的アルゴリズム、シミュレーテッドアニーリング、ベイズ最適化、ランダムサーチを実装し、計算時間と解の質をType 1〜3それぞれで量子手法と比べます。

### 【克服すべき課題と解決策】

**課題1：代理モデルの精度**

ABMは非線形のため、二次近似がどこまで通用するかが一番の不確実要素です。Phase 1のWeek 5-6で早めに確認し、R² > 0.7なら続行、< 0.7なら方針を変えます。

- Plan A：サンプル数を10000点まで増やす（実行時間10秒、許容範囲）
- Plan B：ランダムフォレストで効いている変数を絞り込んでから二次近似する
- Plan C：エージェント間の相互作用を段階的に弱め、二次近似が成り立つ範囲を探る

**ABMの複雑さと代理モデル精度の系統的調査：**

「二次近似が成り立つのはどこまでか」を正面から調べることが、このプロジェクトの中核的な知見になります。

| レベル | ABMの特徴                        | 調べたいこと                                 |
| ------ | -------------------------------- | -------------------------------------------- |
| L1     | 線形ルール、相互作用なし         | 二次近似の上限精度（基準値）                 |
| L2     | 非線形ルール（閾値・段階的反応） | 非線形性が精度にどう影響するか               |
| L3     | 強いエージェント間相互作用       | 創発的挙動で近似が崩れ始める境界             |
| L4     | 確率的行動ルール                 | ランダム性が代理モデルを成り立たなくする条件 |

**課題2：QUBO変換の技術的難しさ**

多項式回帰の係数をQUBO行列に直接マッピングする方法（金融ポートフォリオ最適化の定式化を参考にする）で進めます。制約条件はペナルティ項として加えます。PyQUBOの基礎はナップサック問題等で動作確認済みです。

**課題3：量子が古典を上回らない可能性**

これは最初から覚悟しています。「量子が必ず勝つ」を示すことが目的ではなく、「どの条件なら量子が有利で、どこが限界か」を明らかにすることが目的なので、量子が負けた結果も立派な知見です。「代理モデルの精度がNを超えると古典が安定する」「Type 1・2では拮抗、Type 3のハイブリッドで差が出る」といった形で報告します。

**プログラミング・開発実装**

高校時代からPythonで数理シミュレーションを独学してきました。ABMを実装して武蔵野大学数理工学コンテストに論文として応募した経験があります。Web開発ではReact・Supabase・Vercelを組み合わせたプロダクト開発が得意で、GitHub ActionsによるCI/CD構築も実務（株式会社co-conv、OSディスクイメージ配信システム）で経験しています。制作物例：[magarikado.net/projects](https://www.magarikado.net/projects)

**アルゴリズムと量子コンピューティング**

AtCoder最高レート「緑」（[atcoder.jp/users/magarikado](https://atcoder.jp/users/magarikado)）。動的計画法やグラフアルゴリズムなど、計算量を意識した実装には慣れています。京大電気電子工学科の授業で量子力学・量子情報の理論を学びました。PyQUBOを用いたチュートリアルを一通り実施し、100変数規模のナップサック問題を古典SAで解いてGreedy法との比較実験を行いました。また、本プロジェクトの核心である「代理モデル係数からQUBO行列を構築する処理」についても、スクラッチでの実装と精度検証を完了しています（[証拠コード：github.com/magarikado0/qubo](https://github.com/magarikado0/qubo)）。

高校時代に自作した経済シミュレーションは、個人と企業のエージェントが相互作用してGDPやジニ係数が生まれるという、今回のABMとほぼ同じ構造でした。この段階からジニ係数を指標として扱っており、その成果を武蔵野大学数理工学コンテストに提出しています（[論文PDF](https://drive.google.com/file/d/1pYcZZpAlx6QKk3naPAW_LERHmbjQ5NRo/view?usp=sharing)）。代理モデル（回帰分析）はscikit-learnを使った実装経験があります。

## ７．将来の量子コンピューティング技術について思うこと・期すること

将来は光量子コンピュータの研究開発に携わりたいと思っています。最初はシンプルな動機でした。量子コンピュータが普及すれば、創薬や都市計画といった難問が解けるようになり、それがそのまま社会をよくすることに繋がると、あまり疑わずに信じていました。

ただ、ここ数年でAIや情報技術が急速に発展するのを間近で見ていると、少し複雑な気持ちになりました。「計算機が賢くなれば人類は幸せになる」という図式が、必ずしも成り立っていないように感じる場面が増えてきたからです。効率や利益の最大化を突き詰める計算が、格差を広げたり不安を煽ったりしている側面もある。単に「速く、正確に計算できる」という能力の延長に、私たちが本当に目指すべきものがあるとは言い切れなくなってきました。

光量子コンピュータという、さらに強力な計算機を作ることに本格的に取り組む前に、「計算の進化」が経済政策という泥臭くて複雑な領域でどう機能するかを自分で確かめておきたい。それが今回のプロジェクトを提案した動機のひとつです。ABMでは、一人一人の「税率が上がったから今月は出費を抑えよう」というごく小さな判断が積み重なってGDPや格差という数字になる。その積み重ねを量子技術で最適化しようとするとき、計算が本当に「人のため」に動いているかどうかを体感できると思っています。

量子コンピューティング技術に期待するのは、人間の判断を奪うブラックボックスではなく、より良い選択を後押しする道具になることです。このプロジェクトを通じてその感触を掴めたら、光量子コンピュータの基礎研究に進む際の軸が一段はっきりします。
