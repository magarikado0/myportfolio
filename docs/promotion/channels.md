## 検討中

### X（Twitter）
- 技術系コミュニティが活発
- 記事投稿時に要約を140字でツイート
- ハッシュタグ例: #個人開発 #ハッカソン #量子コンピュータ

### Zenn / Qiita
- 技術記事のクロスポスト先
- SEO 流入が見込める
- Zenn はスクラップ機能で途中経過も書きやすい

### connpass・イベントページ
- イベント参加後に参加記を書いてリンクを貼ってもらう
- 登壇後のスライドにブログ URL を載せる

### GitHub プロフィール
- README にブログへのリンクを追加
